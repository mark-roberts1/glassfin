A Jellyfin television client for the living room — built for a remote and a game controller, not a keyboard.

View on GitHub Build it

Three metres, a D-pad, and about eight usable buttons

Glassfin plays the films and television shows on your Jellyfin server, on a television, from a sofa. Every part of it is reachable with a game controller or a remote — nothing needs a mouse, a keyboard or a terminal in normal use. It's a Flutter client with media_kit (libmpv) doing playback, so video is a widget rather than a layer sitting behind a browser.

What it does

Built for a couch

Directional navigation reaches everything on screen, with focus that's always visible and never lost.

Real playback

libmpv decodes, not a browser — hardware decoding, audio passthrough, and formats that would otherwise force a transcode.

Direct play and transcode

Mid-playback audio and subtitle switching on both paths, including burned-in subtitles when the server has to encode them.

Gamepad & remote input

Reads the same input-map format Jellyfin Media Player used, so existing controller and remote mappings keep working.

Movies and TV, only

No music, no live TV. A deliberate narrowing of scope, not a missing feature.

Intro/outro skipping

Reads Jellyfin's native media segments (10.10+) or the Intro Skipper plugin, when the server has either.

Core playback, browsing and gamepad input are built and working against a real Jellyfin server. HDMI-CEC and Wayland refresh-rate switching are still open — see the project notes for what's left and why.

Get it

There's no packaged release yet. Build it from source — see the README for the Flutter build and the Flatpak packaging script, which is how it's meant to run on a television.
